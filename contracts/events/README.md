# Схемы событий

Модули сообщают друг другу о произошедшем через события. Каждое событие описано JSON Schema в этой папке до того, как его начнут отправлять.

## Имена

`<модуль>.<сущность>.<что случилось>.v<версия>.json`, например `study.submission.created.v1.json`.

## Правила

- Событие говорит о том, что уже случилось, в прошедшем времени.
- В событии только идентификаторы и то, что нужно получателю. Личные данные получатель берёт через открытый интерфейс модуля с проверкой прав.
- Несовместимое изменение — новая версия схемы. Старая версия отправляется, пока её кто-то слушает.
