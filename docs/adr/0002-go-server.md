# 0002. Сервер на Go

Дата: 2026-11-12. Статус: принято.

## Решение

Сервер пишется на Go. Python используется только в ИИ-сервисе.

## Почему

- Собирается в один файл без зависимостей, контейнер весит десятки мегабайт.
- Мало памяти на соединение, тысячи WebSocket на одном сервере.
- Простой язык, код читается одинаково у всех.

## Правила

- HTTP на стандартной библиотеке `net/http`, сторонний роутер только через новое решение.
- Логи через `log/slog` в формате JSON, без личных данных.
- Конфигурация только из переменных окружения.

## Отвергнуто

Node.js и Python для основного сервера: тяжелее по памяти и сложнее держать строгие границы модулей.
