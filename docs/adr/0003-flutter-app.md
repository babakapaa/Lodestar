# 0003. Одно приложение на Flutter

Дата: 2026-11-12. Статус: принято.

## Решение

Одно приложение на Flutter для Android, iOS, Windows, macOS, Linux и веба, одно для всех ролей. Первыми выпускаются Android, веб и Windows.

## Почему

- Один код и одинаковый интерфейс на всех платформах.
- Своя отрисовка: анимации и темы выглядят одинаково везде.
- Локальная база (Drift) даёт работу без интернета.

## Правила

- Состояние через Riverpod, переходы через go_router.
- Цвета, шрифты, отступы и скругления только из токенов `app/lib/design/`.
- Строки только из файлов перевода `app/lib/l10n/`.
- Папки повторяют модули сервера: `core`, `design`, `features/<модуль>`.

## Отвергнуто

Отдельные нативные приложения: в несколько раз больше работы. React Native и веб-обёртки: хуже плавность и офлайн.
