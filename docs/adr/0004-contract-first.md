# 0004. Сначала контракт, потом код

Дата: 2026-11-12. Статус: принято.

## Решение

Каждый запрос API сначала описывается в `contracts/openapi.yaml`, каждое событие в `contracts/events/`. Клиент приложения генерируется из контракта.

## Почему

Клиент и сервер не могут разойтись: несовпадение видно на проверке, а не у пользователя.

## Правила

- Ошибка сервера — это код (`code`), текст для человека подставляет приложение на его языке.
- Несовместимое изменение API идёт только в новой версии пути (`/v2/...`), старая живёт минимум два выпуска.
- Контракт проверяется линтером в CI.
