# 0005. Один репозиторий для всего

Дата: 2026-11-12. Статус: принято.

## Решение

Сервер, приложение, ИИ-сервис, контракты и установка лежат в одном репозитории.

## Почему

Изменение контракта, сервера и приложения проходит одним pull request и проверяется вместе.

## Правила

- Каждая часть собирается и тестируется отдельной задачей CI.
- Общие команды в `Makefile` в корне.
- Новая часть получает свою папку в корне и строку в README.
