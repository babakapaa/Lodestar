# 0027. Движок CRDT в приложении: свой крейт на yrs

Дата: 2026-11-12. Статус: принято.

## Решение

Слияние правок заметок в приложении делает пакет `app/packages/lodestar_crdt`. Внутри него свой маленький крейт на Rust поверх yrs 0.28, наружу он отдаёт Dart-интерфейс `CrdtText`: текст, длина, вектор состояния, применение правки, разница для другой копии, правка по позиции.

## Как устроено

- Логика в `rust/src/engine.rs`. Поверх неё два тонких слоя: C ABI (`ffi.rs`) для Android, iOS, Windows, macOS и Linux и wasm-bindgen (`web.rs`) для веба.
- Нативная библиотека собирается хуком сборки Dart (`hook/build.dart`, native_toolchain_rust), отдельных шагов для разработчика нет, нужен только Rust из `rust-toolchain.toml`.
- Для веба `tool/build_web.sh` собирает wasm и JS-обвязку в `app/web/crdt/`. Приложение подгружает модуль при старте через `CrdtText.ensureReady()`. Сгенерированные файлы в git не хранятся.
- Позиции в тексте считаются в UTF-16, как в полях ввода Flutter, поэтому эмодзи и казахские буквы не сдвигают курсор.
- Ошибки входа (битая правка, позиция за концом текста) дают `CrdtException`, а не падение приложения.
- Тесты пакета идут на VM, в Chrome через dart2js и через dart2wasm. Крейт проверяется `cargo test` с перекрёстной синхронизацией трёх копий на случайных правках.

## Почему

`yjs_dart` теряет правки (ADR 0026), а готовые обёртки над yrs для Dart тянут незрелый wasm_run. Свой крейт из сотни строк проще проверить и обновлять, формат правок у него тот же, что у Yjs.
