# 0036. Чаты на сервере

Дата: 2026-11-13. Статус: принято.

## Решение

- **Модуль `chat`.** Три вида чатов: личный (`direct`, один на пару людей), группа (`group`) и канал (`channel`). Роли в чате: владелец, админ, участник. В канале пишут только владелец и админы. Группу может создать любой, канал только тот, у кого есть право `chat.channels.create`: вуз сам решает, кому его дать.
- **Списки из других модулей.** Ядро получило интерфейс `module.RosterSource`: модуль отдаёт списки людей (`Roster`: ведущие, участники, архив), чат не читает чужие таблицы. Учёба отдаёт курсы (`study.course`): преподаватели становятся админами, студенты из списка курса и из групп курса становятся участниками. Фоновая задача раз в минуту создаёт канал каждого курса и сверяет участников. Группу курса для обсуждений преподаватель создаёт одной кнопкой (`POST /v1/chat/chats` с `origin`), участники приходят сами. Участников из списка курса нельзя удалить вручную, они уходят вместе со списком. Когда курс в архиве, его чаты только для чтения.
- **Сообщения.** У сообщения два номера: `seq` задаёт порядок, `rev` меняется при каждой правке и удалении. Приложение листает историю назад по `before=seq` и догоняет изменения по `since=rev`, поэтому история хранится на устройстве и обновляется без полной загрузки. Повторная отправка с тем же `clientId` не создаёт дубль, так работает очередь отправки без сети. Текст хранится зашифрованным, удалённое сообщение остаётся пустой меткой.
- **Доставка.** Новое сообщение, правка, прочтение и смена состава приходят живым событием (`chat.message`, `chat.read`, `chat.changed`) без текста, приложение само забирает изменения. Пуш `chat.message` получают участники, кроме автора и тех, кто выключил звук в этом чате. В пуше только название чата и имя автора, без текста.
- **Прочтение без слежки.** В канале у сообщения видно только число просмотров. В группе отметок прочтения нет. В личном чате собеседник видит, до какого сообщения прочитано.

## Почему

Механика 7: мессенджер как Telegram, но связан с учёбой. Каналы и группы курса создаются сами из расписания и списков, преподаватель не видит, кто именно прочитал объявление, вуз не читает переписку.

## Отложено

Файлы, упоминания, «Запросы» от незнакомых, блокировка и жалобы, поиск по чатам и сроки хранения сделаем в 5b. Чаты учебных групп со старостой, реакции, голосовые и «Спросить навигатор» добавим позже.
