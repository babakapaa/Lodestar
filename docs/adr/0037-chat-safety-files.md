# 0037. Чаты: файлы, упоминания, запросы, блокировка, жалобы и сроки хранения

Дата: 2026-11-13. Статус: принято.

## Решение

- **Файлы.** К сообщению можно приложить до 10 своих загруженных файлов, текст тогда необязателен. Файл читают только участники чата (`files.Link`). Когда сообщение удалено, файл больше не считается занятым.
- **Упоминания.** Приложение передаёт список упомянутых, сервер оставляет только участников чата. Упомянутый получает отдельное уведомление `chat.mention`, даже если выключил звук в чате.
- **Запросы.** Если у двух людей нет общей группы или канала, первый личный чат попадает собеседнику в «Запросы» (`request`): сообщения приходят, но не звонят. Ответ или кнопка «Принять» переносят чат в обычные.
- **Блокировка.** Заблокированный не может написать и открыть личный чат (`blocked`). Список своих блокировок видит только сам человек.
- **Жалобы.** В жалобу попадают только выбранные жалующимся сообщения, их копия хранится зашифрованной. Жалобы читает тот, кому вуз дал право `chat.reports.review`.
- **Поиск.** Общий поиск находит свои группы и каналы по названию. Текст сообщений сервер не ищет, он зашифрован: по истории ищет приложение у себя.
- **Сроки хранения.** Настройка `chat.retention_days` (0 — хранить всегда). Раз в час старые сообщения становятся пустыми метками, приложение узнаёт об этом при обычной догрузке изменений.

## Почему

Механика 7: писать можно любому из своего вуза, незнакомые попадают в «Запросы», есть блокировка и жалоба, вуз не читает переписку, сроки хранения решает вуз.
