# 0039. Чаты в приложении: файлы, упоминания, участники и жалобы

Дата: 2026-11-13. Статус: принято.

## Решение

- **Файлы.** В ядре приложения появился `FileTransfer`: он создаёт файл на сервере, загружает байты по выданной ссылке и подтверждает загрузку. Скачивание идёт через ссылку `download` и сохраняется через `ExportSaver`. Чаты загружают вложения при выборе, а в очередь отправки кладут уже готовые `fileIds`. Поэтому сообщение без сети уходит позже, а выбрать файл без сети нельзя.
- **Очередь.** В строке очереди хранятся `mentions` и `files` в JSON. База ещё не выпускалась, поэтому схема v1 изменена без миграции.
- **Упоминания.** Ввод `@` показывает участников чата. Выбранный человек попадает в `mentions`, только если `@Имя` осталось в тексте.
- **О чате.** Экран `/chats/:id/info`: название и описание, звук, участники, добавление и исключение по правилам сервера, выход, блокировка в личном чате. Участников из расписания исключить нельзя.
- **Курс.** На экране курса есть плитка «Чаты курса». Канал курса создаётся сервером сам, преподаватель может добавить группу курса.
- **Жалобы.** «Пожаловаться» отправляет только выбранное сообщение и причину. Модератор с правом `chat.reports.review` видит жалобы в администрировании и отмечает их разобранными.
