# 0048. Лига в приложении

Дата: 2026-11-13. Статус: принято.

## Решение

- **Отдельный раздел `features/league`.** Лига открывается по своей арене: `/league/{kind}/{id}`. Для курса это плитка «Лига» на экране курса. Те же пути сервер кладёт в уведомления, поэтому переход из уведомления открывает нужный экран.
- **Студент.** Видит свой дивизион, баллы, сколько осталось до следующего дивизиона, рост к прошлому сезону и часы GPU. Таблица показывает только его дивизион. Студент сам выбирает, как его показывать: по имени, под ником или скрыто. Каждое начисление и переход можно оспорить с объяснением. Видны формула подсчёта, свои споры и награды.
- **Преподаватель.** Подтверждает или отклоняет переходы вверх, отвечает на споры с поправкой баллов, ведёт список участников. В карточке участника можно поправить баллы с причиной и вручить награду. Правила лиги редактируются на отдельном экране: дивизионы с порогами и часами GPU, подтверждение переходов, вес каждой работы. Закрытие сезона требует подтверждения.
- **Задачи лиги.** Преподаватель публикует и закрывает задачи. Студент собирает команду через общий экран команд и предлагает решение команде: текст и ссылки. Преподаватель видит решения с составом команды, предупреждение о похожем прошлом проекте и оценивает решение, отмечая, кто его защитил. Команда может объяснить, чем её решение отличается.
- **Имена в решениях.** Сервер отдаёт в задаче список людей из показанных решений и арену лиги, чтобы приложение не запрашивало их отдельно.
- **Каталог наград.** Пункт «Награды лиги» в администрировании виден с правом `league.awards.manage`: создание, лимит, часы GPU и архив.
