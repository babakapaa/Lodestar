# 0050. Синхронизация курсов с LMS

Дата: 2026-11-13. Статус: принято.

## Решение

- **Что синхронизируем.** Для каждого курса LMS, привязанного к объекту Lodestar, сервер раз в 30 минут и по кнопке «Синхронизировать» забирает участников (NRPS), задания и оценки (AGS). Токен сервиса LMS получаем по client_credentials с подписью ключом Lodestar.
- **Участники.** Активные участники LMS получают аккаунты так же, как при входе из LMS, и добавляются в курс: преподаватели в преподаватели, остальные в студенты. Удалять из курса Lodestar по сигналу LMS не будем: это может стереть доступ к работам и оценкам. Список участников LMS у нас обновляется полностью.
- **Откуда задания.** Настройка вуза `core.lti_assignment_source`: `lodestar` (по умолчанию) — задания создаются в Lodestar, а в LMS появляются колонки оценок; `lms` — задания приходят из LMS и становятся заданиями Lodestar с баллами; `units` — выбор передан подразделениям: его меняет тот, кто управляет курсом Lodestar (право вести курсы в его подразделении). Выбор можно менять в любой момент, например между семестрами.
- **Оценки.** Итоговые баллы Lodestar (после защиты, если она есть) уходят в LMS только по связанным колонкам и только при изменении. В LMS уходят только балл и максимум, без отзывов и материалов.
- **Модули.** Источник привязки (`module.LinkSource`) умеет добавлять участников (`Enroll`) и создавать или обновлять работу из LMS (`PutWork`). Баллы берутся из `module.ScoreSource` того же вида.
- **Ошибки.** Ошибка LMS сохраняется у курса (`syncError`) и видна преподавателю, ручная синхронизация отвечает 502 `lms_unavailable`.
