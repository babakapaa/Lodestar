# 0056. Песочница GPU: простой, сторож, уведомления и возврат

Дата: 2026-11-13. Статус: принято.

## Решение

- **Агент присылает технические метрики.** Для работающего контейнера: загрузка процессора из `docker stats`, байты по сети, имена процессов из `docker top`, загрузка карты из `nvidia-smi`, если он есть. После завершения агент присылает последние 100 строк вывода. Содержимое файлов, код и данные студента агент не читает.
- **Простой решает сервер.** Запуск активен, если процессор или карта загружены хотя бы на 5% или по сети прошло 256 КБ с прошлой сверки. Сеанс Jupyter или VS Code без активности 20 минут получает одно уведомление, через 30 минут он останавливается с причиной `idle`. Файлы остаются в папке владельца. Фоновые задачи по простою не останавливаются, их ограничивает `maxHours`. Если агент не присылает метрики, сервер ничего не останавливает.
- **Сторож ставит на паузу, а не удаляет.** Если среди процессов есть имя из настройки `sandbox.watch_processes` (по умолчанию известные майнеры), запуск получает статус `held`, причину `watchdog` и признак в `holdNote`. Агент делает `docker pause`. Студент видит причину. Решает только администратор с правом `sandbox.manage`: продолжить или остановить. ИИ и преподаватель не решают. Время на паузе не списывается и не считается в `maxHours`. Запуск на паузе держит резерв квоты.
- **Три вида уведомлений.** Задача готова или упала (`sandbox.run_finished`, `sandbox.run_failed`), сеанс скоро остановится (`sandbox.idle`), осталось меньше 10% часов (`sandbox.quota_low`, один раз при пересечении порога, для команды всем участникам). Остановка самим студентом и по простою не уведомляет.
- **Возврат за ранний сбой.** Если запуск упал в первые 5 минут работы, часы не списываются, у запуска `refunded`.
- **Подсказка про экономию.** Средняя загрузка карты хранится в `gpuLoad`. Приложение по ней советует взять карту попроще.
- **Пауза студента без потерь.** Отдельного статуса нет. Остановка сохраняет файлы в папке владельца, а «Продолжить» создаёт новый запуск с той же папкой (этап 9e).
