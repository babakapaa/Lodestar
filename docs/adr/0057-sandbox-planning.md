# 0057. Песочница GPU: оценка, ночь, стартовые проекты, демо, повтор и выгрузка

Дата: 2026-11-13. Статус: принято.

## Решение

- **Оценка до запуска.** `POST /v1/sandbox/estimate` показывает по каждому классу карт наибольшую цену (она же резерв), ночную цену, свободные карты, длину очереди и хватит ли часов. «Подобрать за меня» берёт `suggested`: из классов, на которые хватает часов, сначала тот, где свободных карт больше, чем ждущих, потом с короткой очередью, потом дешевле.
- **Ночная скидка.** Настройки `sandbox.night_discount` (по умолчанию 50%), `sandbox.night_from` (23) и `sandbox.night_to` (7) в часовом поясе вуза `core.time_zone`. Скидка считается по доле ночного времени в запуске. Вуз может выключить её, поставив 0. Резерв остаётся по полной цене.
- **Стартовые мини-проекты.** Окружение с флагом `starter` запускается бесплатно, не дольше 15 минут и только одно за раз у студента. Командой его не запускают.
- **Демо.** Вид запуска `demo`: команда студента слушает порт 8000, ссылка видна владельцу, приложение показывает её QR-кодом на защите. Демо работает во внутренней сети вуза, по умолчанию 2 часа. Постоянный хостинг только как награда, позже.
- **Повтор.** `POST /v1/sandbox/runs/{id}/rerun` создаёт новый запуск с теми же настройками и той же папкой. Это и есть «Продолжить» после паузы.
- **Выгрузка.** `GET /v1/sandbox/runs/export?format=csv|xlsx` отдаёт всю историю своих запусков.
- **Темп квоты.** В квоте есть `spent` и `forecast`: сколько потрачено и сколько останется к концу семестра при нынешнем темпе.
