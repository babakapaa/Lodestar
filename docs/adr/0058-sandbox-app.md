# 0058. Песочница GPU в приложении

Дата: 2026-11-13. Статус: принято.

## Решение

- **Раздел `features/sandbox`.** Вход из «Учёбы» и со страницы задания («Запустить на GPU»), только когда модуль `sandbox` включён у вуза. Администратор видит раздел в администрировании по праву `sandbox.manage`.
- **Баланс как у телефона.** Остаток, полоса от выданного, резерв под идущие запуски, прогноз к концу семестра и строки «откуда часы». Часы можно перевести в запас команды.
- **Запуск с оценкой.** Форма сразу спрашивает `/v1/sandbox/estimate` и показывает цену по каждой видеокарте, ночную цену, очередь и сколько можно потратить. Подобранная карта выбирается сама, «Подобрать за меня» возвращает к ней. Кнопка запуска закрыта, пока есть понятные пропуски: название, окружение, команда, предел времени, карта, часы.
- **Страница запуска.** Статус и место в очереди обновляются раз в 15 секунд, пока запуск идёт. Ссылка на Jupyter, VS Code или демо видна только владельцу; у демо есть QR-код для защиты. Причины остановки, пауза сторожа, возврат часов, совет взять карту попроще и последние строки вывода показаны словами. «Запустить снова» продолжает работу с той же папкой. Для задания курса можно попросить часы у преподавателя.
- **Запросы часов.** Один экран: свои запросы и запросы студентов, которые ждут решения преподавателя.
- **Администрирование.** Запуски на паузе у сторожа (продолжить или остановить), семестры квоты, классы видеокарт, окружения со стартовым флагом и серверы. Ключ сервера показывается один раз сразу после добавления.
- **Пакеты.** `url_launcher` открывает ссылку сеанса, `qr_flutter` рисует QR-код.
- **Отложено.** «Почему упало?» через навигатор: сейчас есть причина, код выхода и вывод, а разбор навигатором добавим вместе с передачей текста в новый диалог.
