# 0062. Статистика вуза по подразделениям

Дата: 2026-11-13. Статус: принято.

## Решение

- **Где смотреть.** `GET /v1/stats/units?parent&days` показывает подразделения на один уровень ниже `parent`, или верхний уровень вуза, если `parent` не указан. Период задаётся в днях: по умолчанию 30, не больше 400. Люди в подразделении считаются вместе с вложенными подразделениями.
- **Права.** Право `core.stats.view` выдаётся на вуз или на подразделение. Декан видит свой факультет и всё, что внутри, но не соседние факультеты. Право `core.stats.full` снимает порог. Его стоит давать только тем, кому вуз доверяет данные небольших групп.
- **Порог 5.** Подразделение, где меньше 5 человек, приходит с `hidden: true`, без числа людей и без показателей. Порог зашит в код. Данных об отдельных людях API не отдаёт никогда.
- **Показатели дают модули.** Модуль реализует `module.StatsSource` и получает список людей подразделения и период. В ответ он возвращает показатели `{key, value}`:
  - `study.submitted`: доля людей, сдавших хотя бы одну работу;
  - `study.on_time`: доля работ, сданных в срок;
  - `attendance.rate`: доля посещённых занятий, уважительные пропуски не считаются;
  - `navigator.users`: доля людей, задававших вопросы навигатору;
  - `sandbox.hours`: часы GPU.

  Если считать не из чего, модуль не возвращает показатель. Тогда приложение показывает прочерк, а не ноль.
- **Чего нет.** Здесь нет рейтингов преподавателей, опросов и сравнений людей между собой. Это сознательно, чтобы панель не превратилась в слежку.
- **В приложении.** В администрировании появился раздел «Статистика вуза». Он виден, если право `core.stats.view` выдано на весь вуз. В разделе можно выбрать период (неделя, месяц, 3 месяца, год) и переходить вглубь по подразделениям. Доли показываются полосками, часы GPU числом.

  Если право выдано только на факультет или кафедру, в профиле появляется пункт «Статистика: <подразделение>» (`GET /v1/stats/entries` отдаёт такие подразделения). Добавлено 13.11.2026.
- **Решения вуза.** Настройки вуза на экране теперь разбиты на разделы: «Общее», «Право и данные», «Учёба», «Навигатор», «Посещаемость», «Песочница GPU» и «Другое». Раздел определяется по ключу настройки. Те же разделы будут в мастере установки (10e).
