# 0063. Мастер установки

Дата: 2026-11-13. Статус: принято.

## Решение

- **Когда вуз в мастере.** `lodestarctl tenant create` создаёт вуз в режиме настройки (строка в `core.setup_state`). Флаг `--ready` создаёт вуз сразу открытым. Вузы, созданные раньше, и тестовый вуз demo считаются запущенными.
- **До запуска.** Пока вуз не запущен, модули отвечают `403 university_not_launched`. Исключение: люди с правом `core.setup.manage` и те, кому поручен раздел. `GET /v1/setup/status` доступен всем, по нему приложение показывает, что вуз ещё настраивается.
- **Разделы.** Разделов 13, как в концепции 10.9:
  - развёртывание;
  - вуз и структура;
  - вход и люди;
  - администраторы;
  - интеграции;
  - обучение;
  - навигатор;
  - лига;
  - песочница;
  - быт вуза;
  - данные;
  - «Право и безопасность»;
  - запуск.

  Обязательны первые четыре и «Право и безопасность». Раздел настройки определяется по её ключу (`setup.SectionOf`). Тот же порядок используется в «Решениях вуза».
- **Поручения.** Владелец поручает раздел человеку и может указать срок. Этот человек видит только свой раздел, меняет его настройки через `/v1/setup/sections/{section}/settings/{key}` и отправляет раздел на проверку. Владелец утверждает раздел или возвращает его с комментарием. Раздел «Право и безопасность» поручается только человеку с правом `core.setup.legal`. При запуске все поручения снимаются.
- **«Право и безопасность».** В разделе 8 вопросов. На каждый нужен ответ и основание (статья закона или приказ вуза), значения «по умолчанию» здесь нет. Ответ утверждает человек с `core.setup.legal`. Из ответов собирается «Протокол подключения» (`GET /v1/setup/protocol`, с `format=md` отдаётся файлом). Протокол подписывает человек с `core.setup.sign`, и каждая подпись создаёт новую версию. Любое изменение ответа снимает подпись.
- **Готовность.** Запуск не пройдёт, пока есть проблемы:
  - обязательный раздел не утверждён;
  - есть неутверждённые ответы;
  - протокол не подписан;
  - в вузе нет ни одного подразделения;
  - проблемы от модулей (`module.ReadinessSource`). Сейчас это курсы без преподавателя (study) и не подключённая модель навигатора (navigator). Модуль сообщает о проблеме, только если он включён.
- **Отложено:**
  - протокол в PDF (сейчас файл Markdown);
  - напоминание за день до срока;
  - приглашения письмом;
  - пилотный запуск на выбранных курсах;
  - просмотр «глазами студента»;
  - автопроверка железа;
  - конструктор особых правил;
  - выбор, может ли кафедра менять настройку.
