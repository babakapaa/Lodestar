# 0066. Вложения при сдаче и расписание в приложении

Дата: 2026-11-13. Статус: принято.

## Решение

- **Вложения.** К сдаче можно прикрепить до 20 файлов. Файл загружается сразу, как в чатах, поэтому для прикрепления нужна сеть. Сама сдача по-прежнему уходит через очередь и хранит id файлов. Работу можно сдать одними файлами, без текста.
- **Скачивание.** Файлы задания, своей работы и работы студента в оценивании скачиваются по нажатию (`FileDownload`, его же использует чат).
- **Расписание курса.** У преподавателя и у тех, кто управляет расписанием, на курсе есть раздел «Расписание курса»: повторяющиеся занятия (добавить, изменить, удалить) и занятия на ближайшие две недели. Занятие можно отменить с комментарием, перенести, сменить аудиторию и вернуть как было. Права проверяет сервер: если вуз запретил преподавателям менять расписание (`study.teachers_edit_schedule`), приложение показывает ошибку.
