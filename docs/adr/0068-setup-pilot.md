# 0068. Пилотный запуск на выбранных курсах

Дата: 2026-11-13. Статус: принято.

## Решение

- **Запуск.** `POST /v1/setup/launch` принимает необязательный список `pilot` (до 200 курсов). Пустой список или тело без него означает запуск для всех. Курсы берутся из `GET /v1/setup/pilot/courses`; чужой или повторный id даёт `400 invalid_setup_pilot`.
- **Кому открыто.** В пилоте приложение открыто преподавателям и студентам выбранных курсов (включая студентов из групп курса) и тем, у кого есть `core.setup.manage`. Остальные получают `403 university_not_launched`, а `GET /v1/setup/status` отвечает `pilot: true, included: false`, и приложение показывает, что Lodestar пока работает пилотом.
- **Курсы для пилота** даёт модуль через `module.PilotSource`. Сейчас это только study. Если модуль выключен, пилот выбрать нельзя.
- **Открыть для всех.** `POST /v1/setup/expand` снимает пилот. Запись в журнале `core.setup.expanded`. Список курсов хранится в `core.setup_state.pilot_courses`.
- **В приложении.** Кнопка «Запустить» спрашивает: для всех или пилотом, и в пилоте даёт отметить курсы. После запуска в мастере есть карточка «Пилот» с кнопкой «Открыть для всех».
