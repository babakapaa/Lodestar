# 0070. Звонки в каналах

Дата: 2026-11-13. Статус: принято.

## Решение

- **Кто начинает.** В канале (в том числе в канале курса) звонок начинает только владелец или администратор канала. Участник канала может только войти в идущий звонок, иначе `409 call_not_started`.
- **Размер.** В звонке канала до 300 человек, в личных и групповых чатах по-прежнему до 50. Ограничение по числу участников чата для каналов не действует, считаются только те, кто вошёл.
- **Микрофон.** Участник канала входит с выключенным микрофоном (`muted` в билете), но может включить его сам, например чтобы задать вопрос. Права на камеру и микрофон те же, показ экрана и запись по правилам вуза (`chat.screen_share`, `chat.call_recording`).
- **Уведомление.** Когда администратор начинает звонок, участники канала получают обычное уведомление о звонке.
- **В приложении.** Кнопка звонка в канале есть только у администраторов, остальные входят через плашку идущего звонка.
