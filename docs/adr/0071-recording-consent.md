# 0071. Согласие на запись и запись только звука

Дата: 2026-11-13. Статус: принято.

## Решение

- **Правило вуза.** Новая настройка `chat.recording_consent` в разделе «Право и безопасность», по умолчанию включена. Если вуз её выключит, запись идёт как раньше: только с меткой.
- **Просьба о записи.** Когда правило включено, `POST /v1/chat/calls/{id}/recording` не начинает запись сразу, а создаёт просьбу. В звонке появляется `consent` с тем, кто просит, и списком тех, кого ждут. Каждый отвечает через `POST /v1/chat/calls/{id}/consent`. Один отказ отменяет просьбу. Когда согласились все, кто сейчас в звонке, запись начинается от имени того, кто просил. Если ждали только того, кто ушёл, просящий нажимает «Записать» ещё раз, и запись начинается.
- **Вход в записываемый звонок.** Пока идёт запись, войти можно только с согласием (`consent: true` при входе), иначе `409 recording_consent_required`. Приложение спрашивает согласие перед входом.
- **Только звук.** `audioOnly` при начале записи. Egress пишет только звук в OGG, в звонке видно `audioOnly`.
- **Хранение.** Согласие хранится в `chat.call_members.consent` на время звонка, просьба в `chat.calls`.
