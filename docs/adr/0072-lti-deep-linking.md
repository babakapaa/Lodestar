# 0072. Выбор курса из LMS (LTI Deep Linking)

Дата: 2026-11-13. Статус: принято.

## Решение

- **Что это.** Преподаватель в LMS добавляет внешний инструмент, LMS шлёт `LtiDeepLinkingRequest`, Lodestar показывает курсы, которые он ведёт, и возвращает выбранное ссылкой `ltiResourceLink`. Привязывать курс LMS вручную после этого не нужно.
- **Запуск.** Принимаем запрос с `deep_link_return_url`, если в `accept_types` есть `ltiResourceLink`. Запрос учащегося отклоняется. Сервер хранит запрос час в `lti.deep_links` и ведёт приложение на `/lti/deep-links/{id}`; видеть и отвечать на него может только тот, кто пришёл из LMS.
- **Ответ.** `POST /v1/lti/deep-links/{id}` проверяет, что выбранное можно привязать (`CanLink`), число элементов (1–20, один при `accept_multiple=false`), подписывает ответ текущим ключом инструмента (`iss` = client_id, `aud` = issuer LMS, `nonce`, `deployment_id`, `data` из запроса) и отдаёт одноразовый `formUrl`. Страница по нему сама отправляет `JWT` формой на адрес LMS, повторно не открывается.
- **Ссылка.** В элементе `custom` с `lodestar_kind` и `lodestar_id`. При обычном запуске они важнее привязки курса LMS; если место не найдено, работает прежний путь.
- **В приложении.** Экран выбора курсов, кнопка «Вернуться в LMS» открывает `formUrl` в том же окне.
- **Настройка LMS.** Адрес выбора содержимого тот же, что адрес запуска.
