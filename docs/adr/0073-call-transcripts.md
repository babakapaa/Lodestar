# 0073. Расшифровка записи звонка

Дата: 2026-11-14. Статус: принято.

## Решение

- **Правило вуза.** Настройка `chat.call_transcripts` в разделе «Право и безопасность», по умолчанию выключена. Расшифровываются только записи, сделанные после включения.
- **Где распознаётся речь.** На сервере распознавания вуза через OpenAI-совместимый `/audio/transcriptions` (Whisper, faster-whisper, vLLM): `LODESTAR_STT_URL`, `LODESTAR_STT_MODEL`, `LODESTAR_STT_KEY`, `LODESTAR_STT_TIMEOUT` (по умолчанию 30 минут). Язык модель определяет сама. Без сервера расшифровки нет, запись работает как раньше.
- **Как идёт.** Когда запись готова и правило включено, она встаёт в очередь (`chat.call_recordings.transcript`). Фоновый обработчик раз в минуту берёт записи по одной, читает файл из хранилища и отправляет его на распознавание. При сбое повторяет через час, после трёх неудач оставляет запись без расшифровки.
- **Результат.** Текст сохраняется файлом `<запись>-transcript.txt` в том же хранилище и публикуется в том же чате от того, кто начал запись. Дальше это обычное вложение: его видят участники чата, удалить может владелец. Пустой текст не публикуется.
- **Хранилище.** В `files.Storage` добавлен `Put`, модулям он доступен через `module.Objects`.
