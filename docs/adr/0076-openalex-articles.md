# 0076. Статьи из OpenAlex в навигаторе

Дата: 2026-11-19. Статус: принято.

## Решение

- **Зачем.** Если в материалах курса нет ответа, навигатор раньше только советовал запросы и места поиска. Теперь он показывает настоящие статьи с DOI, чтобы студент начинал с проверяемого источника, а не с выдуманной ссылки.
- **Когда ищет.** Только если в материалах курса не нашлось фрагментов, ступень ответа предполагает источник (источник, фрагмент, пример) и настройка вуза `navigator.open_library` включена (по умолчанию да). Модель превращает вопрос в короткий английский запрос, при ошибке берётся сам вопрос.
- **Как ищет.** `GET https://api.openalex.org/works` с `filter=has_doi:true`, пять работ, только название, авторы, год, журнал и DOI. Тайм-аут 8 секунд, при ошибке ответ идёт без статей. В OpenAlex уходит только запрос, без имени студента и текста диалога.
- **Что видит студент.** Под ответом список «Статьи из OpenAlex». Кнопка «В заметки» добавляет статью в источники заметок через тот же поиск по DOI в Crossref, что и ручное добавление. Статьи попадают в журнал вопросов и источников для карты поиска.
- **Отключение.** Вуз выключает поиск настройкой `navigator.open_library`, например если сервер без выхода в интернет.
