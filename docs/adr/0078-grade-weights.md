# 0078. Веса оценки в задании

Дата: 2026-11-19. Статус: принято.

## Решение

- **Зачем.** Главный механизм Lodestar в том, что готовый текст сам по себе не даёт высокой оценки. Раньше веса 50/30/20 были только рекомендацией, и лектор считал итог сам. Теперь их обеспечивает приложение.
- **Задание.** При оценке в баллах лектор включает «Складывать оценку из частей» и задаёт веса защиты, карты поиска и работы в процентах, сумма 100. У нового задания включено с весами 50/30/20, их можно менять или выключить. Веса видит и студент.
- **Оценка.** Лектор ставит результат по каждой части с ненулевым весом от 0 до 100%. Сервер считает баллы: сумма вес × результат, умноженная на максимум, с округлением до сотых, и хранит части вместе с оценкой (`grades.parts`).
- **Последнее слово за лектором.** Он может выключить «Считать по частям» и поставить баллы сам, тогда части не хранятся. ИИ в оценке не участвует.
- **Остальное.** Лига, журнал и передача в LMS работают с итоговыми баллами, как раньше.
