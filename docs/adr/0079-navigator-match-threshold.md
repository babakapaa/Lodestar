# 0079. Порог сходства фрагментов и отозванные статьи

Дата: 2026-11-19. Статус: принято.

## Решение

- **Зачем.** Раньше навигатор всегда брал 5 ближайших фрагментов курса, даже если ни один не подходил к вопросу. Статьи из OpenAlex появлялись только в курсе без материалов, хотя в материалах сказано «если в курсе ничего не подходит».
- **Порог.** Настройка вуза `navigator.min_similarity`, процент от 0 до 100, по умолчанию 40. Фрагмент попадает в ответ, только если косинусное сходство с вопросом не ниже порога. Если ни один не прошёл, навигатор ищет статьи в OpenAlex (ADR 0076). 0 выключает порог.
- **Подбор.** 40% это стартовое значение для bge-m3. Точное значение вуз подбирает на пилоте по своим материалам.
- **Отозванные статьи.** Запрос к OpenAlex идёт с фильтром `has_doi:true,is_retracted:false`, отозванные статьи не показываются.
