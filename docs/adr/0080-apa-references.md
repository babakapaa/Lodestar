# 0080. Список литературы в APA 7

Дата: 2026-11-19. Статус: принято.

## Решение

- **Зачем.** В Казахстане чаще требуют ГОСТ, в англоязычных вузах (например, KIMEP) APA. Раньше приложение оформляло список только по ГОСТ.
- **Как.** На экране источников кнопка «Скопировать список литературы» предлагает ГОСТ Р 7.0.100 или APA 7. APA собирает `ApaReference`: автор, инициалы, год или n.d., название, журнал с томом и выпуском, DOI ссылкой. Список идёт по алфавиту без номеров.
- **Общее.** Разбор имени «Фамилия, Имя» вынесен в `AuthorName`, им пользуются оба формата.
- **Карта поиска.** Запись источника в карте по-прежнему хранится по ГОСТ (ADR 0031).
