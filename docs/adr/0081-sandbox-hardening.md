# 0081. Ограничения контейнера песочницы

Дата: 2026-11-19. Статус: принято.

## Решение

- **Зачем.** Чужой код на GPU вуза запускается в Docker (ADR 0055). Раньше контейнер шёл с настройками Docker по умолчанию.
- **Что добавлено.** Агент запускает контейнер с `no-new-privileges` (нельзя поднять права через setuid и sudo), без возможностей `NET_RAW`, `SYS_ADMIN`, `SYS_PTRACE`, `MKNOD`, `AUDIT_WRITE` и с пределом 4096 процессов.
- **Что осталось.** Контейнер не привилегированный, видит одну карту и свою папку, ограничен временем и квотой, майнеры ловит сторож (ADR 0056). Сеть не закрыта: вуз сам решает, пускать ли GPU-машины в интернет. Отдельного ядра (gVisor, Kata) нет, поэтому GPU-машины лучше держать отдельно от основного сервера.
